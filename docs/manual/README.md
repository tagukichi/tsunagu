# つなぐ依頼ページ 運用マニュアル（納品用スライド）

クライアントにお渡しする運用マニュアルのスライドです。

## ファイル
| ファイル | 内容 |
|---|---|
| `つなぐ依頼ページ_運用マニュアル.pptx` | **納品用スライド（全22枚）** |
| `build.js` | スライドの生成スクリプト（pptxgenjs） |
| `preview.py` | 表示確認用（PPTX→HTMLの簡易プレビュー） |

## 構成（全22枚）
1. 表紙／このマニュアルの内容／サイトの全体像
2. **1章 WordPressへのログイン** … ログイン手順・管理画面の見方・2種類のログインの違い
3. **2章 コンテンツの修正** … 基本の流れ・編集できる項目・修正例3種
4. **3章 フォームについて** … 入力〜送信の流れ・文言/宛先の変更・ボタンとの紐付け
5. **4章 新規ユーザーの登録** … 登録手順・**会社名の入力（最重要）**・運用の注意点
6. 困ったときは（FAQ）

## スクリーンショットの差し込み方
点線枠が **画像プレースホルダー（13箇所）** です。以下の手順で差し替えてください。

1. PowerPoint で該当スライドを開く
2. 点線の枠（と中のアイコン・説明文）を選択して削除
3. 「挿入 → 画像」でスクリーンショットを配置し、空いたスペースに合わせてサイズ調整

必要なスクリーンショットは、各枠内の説明文に記載しています（例：「WordPressのログイン画面のスクリーンショット」）。

## 再生成する場合
```bash
cd docs/manual
npm install pptxgenjs           # 初回のみ
FONT=Meiryo node build.js つなぐ依頼ページ_運用マニュアル.pptx
```

- フォントは `FONT` 環境変数で変更できます（既定：Meiryo）。
- 文言の修正は `build.js` の各スライドのブロックを編集してください。

## 備考
- 本文フォントは **Meiryo**（Windows / Mac の Office で標準的に利用可能）を指定しています。
- 配色はサイトのブランドカラー（ネイビー `#11295A` / ブルー `#1F6FE0` / ゴールド `#C98A16`）に合わせています。
