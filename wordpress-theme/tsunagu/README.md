# つなぐ依頼ページ WordPress テーマ

つなぐ会員向け「依頼ページ」の専用テーマです。文言・リンク・PDF・ポップアップ・TOPIC を **ACF（Advanced Custom Fields）** で編集でき、**会員ログイン（ID/PASS）** による閲覧制限に対応します。
ACF 未導入でも、テーマ同梱の初期内容でそのまま表示されます。

## 動作要件
- WordPress 6.0 以上 / PHP 7.4 以上
- 推奨プラグイン：**Advanced Custom Fields**（無料版でOK。文言等を管理画面から編集する場合に必要）

## セットアップ手順

### 1. テーマを有効化
「外観 > テーマ > 新規追加 > テーマのアップロード」から本 ZIP をアップロードし、**有効化**。

### 2. ACF を導入（編集する場合）
「プラグイン > 新規追加」で **Advanced Custom Fields** をインストール＆有効化。
※ フィールドはテーマ側で自動登録されます（設定不要）。

### 3. 依頼ページ（トップ）を作成
1. 「固定ページ > 新規追加」でページを作成（例：タイトル「依頼ページ」）。
2. 右側「ページ属性 > テンプレート」で **「つなぐ 依頼ページ」** を選択。
3. ACF の入力欄（ヘッダー/ヒーロー/調速/カード1〜6/TOPIC/相談CTA）を編集して公開。
4. 「設定 > 表示設定」で **ホームページの表示＝固定ページ**、ホームページに作成したページを指定。

> テンプレートを割り当てず、固定ページをそのままホームページに設定しても表示されます（front-page.php）。その場合も ACF 入力欄は表示されます。

### 4. ログインページを作成
1. 「固定ページ > 新規追加」でページを作成（**スラッグは `login` 推奨**）。
2. テンプレートで **「つなぐ ログイン」** を選択して公開。
3. （任意）ACF でロゴ・見出し・注記を編集。

### 5. 会員限定アクセスを有効化（自動）
- 上記ログインページが存在すると、**未ログインの訪問者は自動的にログインページへリダイレクト**されます（管理画面・wp-login・REST等は除外）。
- ログインは `wp-login.php` が処理し、成功すると元のページへ戻ります（失敗時はログイン画面にエラー表示）。

### 6. 会員（ユーザー）の登録
- 「ユーザー > 新規追加」で会員を作成（ID・メール・パスワード）。
- 公開登録は無効推奨：「設定 > 一般 >『だれでも登録できるようにする』のチェックを外す」。

## 編集できる項目（ACF）
- **ヘッダー/共通**：ロゴ画像、ヘッダーボタン（利用規約・ダウンロード）ラベル/URL、コピーライト
- **ヒーロー**：バッジ、タイトル、リード文
- **おすすめツール（調速）**：ロゴ画像、リボン、製品名、ピル、説明、ボタン ラベル/URL
- **カード1〜6**：タグ、タイトル、説明、左ボタン ラベル＋PDF（リピーター：1件=直接表示/2件以上=リスト）、右ボタン ラベル＋ポップアップ見出し＋本文（WYSIWYG）。カード4のポップアップは料金表PDF
- **TOPIC**：リピーター（流れるお知らせ）
- **相談CTA**：タイトル、説明、ボタン ラベル/URL
- **ログインページ**：ロゴ、見出し、リード、注記

## 構成
```
tsunagu/
├── style.css                 テーマ情報
├── functions.php             読み込み・会員限定アクセス・ACF登録呼び出し
├── front-page.php            フロントページ
├── template-tsunagu.php      テンプレート「つなぐ 依頼ページ」
├── template-login.php        テンプレート「つなぐ ログイン」
├── header.php / footer.php   共通ヘッダー/フッター
├── header-login.php / footer-login.php  ログイン用
├── index.php / page.php      フォールバック
├── inc/
│   ├── helpers.php           ACF値の取得（既定値フォールバック）
│   ├── defaults.php          初期コンテンツ
│   └── acf-fields.php         ACFフィールド定義（PHP登録）
├── template-parts/
│   ├── content-tsunagu.php   依頼ページ本体
│   └── content-login.php     ログイン本体
└── assets/ (css / js / img / pdf)
```

## 備考
- ポップアップ本文・説明文は管理者（信頼できる編集者）入力前提で出力しています（社内向け会員サイト想定）。
- 画像/PDF はテーマ同梱（`assets/img`, `assets/pdf`）を初期値に使用。ACF で差し替え可能です。
